UMANG site fonts
================
The site is designed for three licensed fonts. Put their web files (WOFF2) in this folder with EXACTLY these names.
Until you do, the site automatically uses Fraunces (titles), Caveat (subtitles and quotes) and EB Garamond (body).

JHC Rasbora (titles) - buy the full family: https://creativemarket.com/JehooCreative/282207594-JHC-Rasbora-Soft-Typography
  JHCRasbora-Light.woff2, JHCRasbora-Regular.woff2, JHCRasbora-RegularItalic.woff2, JHCRasbora-Medium.woff2,
  JHCRasbora-SemiBold.woff2, JHCRasbora-Bold.woff2, JHCRasbora-BoldItalic.woff2, JHCRasbora-ExtraBold.woff2,
  JHCRasbora-ExtraBoldItalic.woff2, JHCRasbora-ExtraBlack.woff2
Birds of Paradise (subtitles and quotes)
  BirdsOfParadise-Regular.woff2
Apple Garamond (body text)
  AppleGaramond-Light.woff2, AppleGaramond-Regular.woff2, AppleGaramond-Italic.woff2,
  AppleGaramond-Bold.woff2, AppleGaramond-BoldItalic.woff2

Convert .otf/.ttf files to .woff2 with any free converter (for example Google's woff2 tool or a "font to woff2" web converter).
Check each font's licence allows website use before uploading.
